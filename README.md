# 🎸 기타 코드 리듬 (수업용)

노래에 맞춰 코드가 위에서 내려오고, 아이들이 **실제 기타로 연주**하면
**선생님이 바로 판정**하는 수업용 리듬 게임입니다.

---

## 곡은 어디에 저장되나요?

**이 폴더 안 `songs/` 에 파일로 저장됩니다.**

```
songs/
  songs.json            ← 곡 목록 + 채보(코드와 타이밍)
  s1a2b3c4.m4a          ← 음원
  s9z8y7x6.mp3
```

그래서 **폴더를 통째로 복사하면 곡이 전부 따라갑니다.** USB, 에어드랍, 아이클라우드 어디로 옮겨도 됩니다.
브라우저를 바꿔도, 컴퓨터를 바꿔도 곡 목록은 그대로입니다. (설정값만 브라우저에 저장돼요.)

---

## 상황별 사용법

### 1. 맥에서 (곡 추가 · 채보 · 수업 모두 가능)

`기타게임.command` 더블클릭 → 브라우저가 열립니다. (또는 터미널에서 `python3 serve.py`)

### 2. 아이패드에서 — 같은 와이파이에 맥이 있을 때

1. 맥에서 `기타게임.command` 실행
2. 터미널에 이런 줄이 나옵니다:
   ```
   아이패드에서(같은 와이파이):  http://192.168.0.12:8799/
   ```
3. 아이패드 **Edge 앱** 주소창에 그 주소를 입력하면 곡 목록이 그대로 뜹니다.
4. 자주 쓰면 **공유 → 홈 화면에 추가** 해두면 앱처럼 전체화면으로 열립니다.

> 맥을 켜 둬야 하고, 같은 와이파이여야 합니다.

### 3. 아이패드만 들고 다른 곳에서 쓸 때 — 웹에 올리기 ★

맥이 없는 곳에서 쓰려면 **한 번만 웹에 올려두면** 됩니다. 곡도 같이 올라갑니다.

1. 맥에서 **`웹에올리기.command` 더블클릭** (GitHub 로그인 창이 한 번 뜹니다)
2. 끝나면 이런 주소가 나옵니다:
   ```
   https://<내아이디>.github.io/guitar-chord-rhythm/
   접속 코드: voxhyeon
   ```
3. 아이패드 **Edge**에서 그 주소를 열고 → **접속 코드 입력** (한 번만 입력하면 기억합니다)
4. **공유 → 홈 화면에 추가** → 앱처럼 전체화면으로 열립니다
5. 수업 전에 **⬇ 오프라인 저장**을 한 번 눌러두세요
   → 그 뒤로는 **인터넷이 없어도** 곡까지 그대로 열립니다 (교실 와이파이가 끊겨도 안전)

곡을 새로 만들거나 고친 뒤에는 `웹에올리기.command`를 다시 누르면 아이패드에도 반영됩니다.
(아이패드에서 새 곡이 안 보이면 ⬇ 오프라인 저장을 다시 눌러주세요.)

이때 아이패드는 **읽기 전용**이 되어 연주만 할 수 있고, 곡 추가·채보는 맥에서 합니다.

#### 접속 코드 바꾸기
`js/access-config.js` 의 `pin: 'voxhyeon'` 을 원하는 코드로 바꾼 뒤 다시 올리면 됩니다.

> ⚠️ 주의: 음원 파일이 인터넷에 올라갑니다. 접속 코드는 **화면 잠금**이라 아이들이 그냥 들어오는 건
> 막아주지만, 파일 주소를 직접 아는 사람까지 막지는 못합니다. 저작권이 민감한 음원이라면
> 2번(같은 와이파이) 방법을 쓰세요.

## 맥 두 대로 쓰기 (인텔 데스크탑 + 실리콘 맥북)

**바탕화면이 아이클라우드로 동기화되므로 따로 설치할 게 없습니다.**
이 폴더가 맥북 바탕화면에도 그대로 생기고, 곡(`songs/`)까지 통째로 따라갑니다.
맥북에서도 `기타게임.command` 를 더블클릭하면 같은 곡 목록이 나옵니다.
스크립트가 맥 종류(인텔/실리콘)를 자동으로 알아보니 파일은 똑같이 쓰면 됩니다.

### 지켜야 할 두 가지

**1. 두 맥에서 동시에 열지 마세요**

한쪽에서 채보하고 **동기화가 끝난 뒤**(Finder에서 폴더 옆 구름/진행 표시가 사라진 뒤) 다른 쪽을 여세요.
동시에 고치면 아이클라우드가 `파일 (2)` 같은 충돌 사본을 만들어 곡이 엉킵니다.

**2. 수업 전에 음원이 내려받아져 있는지 확인하세요**

이 맥은 **'Mac 저장 공간 최적화'가 켜져 있습니다.** 공간이 부족하면 아이클라우드가
안 쓰던 mp3를 컴퓨터에서 비우고 아이콘만 남겨둡니다. 그 상태로 수업에 가면 곡이 안 열려요.

→ `기타게임.command` 를 실행하면 터미널이 **자동으로 점검해서 알려줍니다.**

```
⚠️  바로 열 수 없는 곡이 있습니다:
     · 우리들의 노래 — 아이클라우드에서 내려받아야 함
```

이렇게 나오면 Finder에서 `songs` 폴더를 열고 구름 아이콘(⬇)을 눌러 받아두세요.
아무 경고가 없으면 그대로 쓰시면 됩니다.

### GitHub는 아이패드용입니다

맥끼리는 아이클라우드가 알아서 맞춰주니 `최신곡받기.command` 는 평소에 쓸 일이 없습니다.
**아이패드에 새 곡을 보낼 때만** `웹에올리기.command` 를 누르세요.
(아이클라우드가 꼬였을 때 GitHub에서 되살리는 용도로 `최신곡받기.command` 를 남겨뒀습니다.)

## 곡 추가하고 채보 만들기 (맥에서)

1. **＋ 새 곡 추가 (mp3)** → 음원을 고르면 `songs/` 폴더에 복사되고 채보 화면이 열립니다.
2. 박자 맞추기
   - **BPM** 입력 (모르면 **탭 템포** 버튼을 노래에 맞춰 여러 번 클릭)
   - 노래를 재생하다 첫 박에서 **지금을 첫박으로** 클릭 → 마디선이 노래와 맞습니다.
   - **스냅**을 `1마디` 또는 `1박`으로 두면 코드가 박자에 딱 붙습니다.
3. 코드 찍기 (둘 중 편한 쪽)
   - **멈춰놓고**: 팔레트에서 코드를 고른 뒤 **타임라인 아래쪽(코드 줄)을 클릭**
   - **들으면서**: 재생 중에 코드 버튼이나 **Enter** → 그 순간에 바로 찍힘
4. 수정: 노트 **클릭**(선택) · **드래그**(이동) · **Delete**(삭제), 아래 칩의 **×** 로도 삭제
5. **저장** → `songs/songs.json` 에 바로 기록됩니다. (다운로드 받아 옮길 필요 없어요)

### 채보 화면 단축키
| 키 | 기능 |
|---|---|
| `Space` | 재생 / 정지 |
| `Enter` | 지금 위치에 선택한 코드 찍기 |
| `Delete` | 선택한 노트 삭제 |
| `← →` | 한 박 이동 (`Shift`와 함께 0.1초) |
| `⌘S` | 저장 |

파형 **위쪽**을 클릭하면 그 지점으로 이동, **아래쪽 코드 줄**을 클릭하면 코드가 놓입니다.

## 연주 수업하기

**▶ 연주** → 딱딱딱 카운트 후 코드가 내려옵니다. 코드가 **판정선(점선)에 닿을 때** 아이가 연주합니다.

| 키 | 화면 버튼 | 뜻 | 점수 |
|---|---|---|---|
| `X` | 성공 | 제때 정확히 쳤다 | 100점 + 콤보 보너스 |
| `Z` | 살짝 | 소리는 났는데 아쉽다 | 50점 (콤보 유지) |
| `C` | 실패 | 못 쳤다 / 틀렸다 | 0점 (콤보 끊김) |
| `Space` | 일시정지 | 멈추고 속도 조절·처음부터 | — |

- **아이패드에서는 화면 아래 큰 버튼을 손가락으로 누르면 됩니다** (키보드 없이 수업 가능).
- 아무것도 누르지 않고 지나가면 자동으로 실패 처리됩니다 (설정에서 끌 수 있어요).
- 레인 아래와 옆 패널에 **코드 운지 그림**이 나와 아이가 보고 짚을 수 있습니다.
- 끝나면 성공/살짝/실패 개수, 최대 콤보, 정확도, 별 등급이 나옵니다.

---

## 수업 팁

- **느리게 연습**: 일시정지(`Space`) → 속도 `0.75x` / `0.6x`. 음정은 그대로 느려집니다.
- **코드 읽을 시간이 부족하면**: 설정에서 **낙하 속도**를 3~4초로 늘리세요.
- **판정이 빡빡하면**: 설정의 **판정 가능 구간(늦게)** 를 키우면 넉넉하게 봐줍니다.
- 코드가 **6개 이하**면 코드마다 레인이 하나씩 생겨 같은 코드가 늘 같은 줄로 내려옵니다.
  7개 이상이면 한 줄로 합쳐지고, 지금 칠 코드의 운지가 아래에 크게 나옵니다.
- 처음 배우는 아이에겐 팔레트의 `F(쉬움)`, `G(쉬움)` 운지를 써보세요.
- **아이패드에서 소리가 안 나면**: 측면 무음 스위치와 볼륨을 확인하세요.
- **아이패드에서 곡이 안 보이면**: 주소를 잘못 열었거나(맥 주소는 맥이 켜져 있어야 함),
  웹 주소라면 ⬇ 오프라인 저장을 아직 안 누른 상태에서 인터넷이 끊긴 경우입니다.

## PPT 리모컨으로 판정하기

교실 뒤에서 리모컨만으로 판정할 수 있습니다. (프레젠터, 무선 포인터 — 이름은 달라도 됩니다)

| 리모컨 버튼 | 하는 일 |
|---|---|
| ▶ 다음 | **성공** |
| ◀ 이전 | **실패** |
| ⬛ 화면 끄기 | **살짝** |
| 시작 / 종료 | **일시정지** |

결과 화면에서는 **▶ 다음 = 다시 연주**, **◀ 이전 = 목록으로**. 맥 앞으로 돌아가지 않아도 됩니다.

리모컨은 제품마다 보내는 신호가 다릅니다. **내 리모컨이 되는지 확인하려면**
홈 화면의 **🖱 리모컨 확인**을 누르고 버튼을 하나씩 눌러보세요.
"이 버튼 = 성공" 처럼 알려줍니다. 안 되는 버튼이 있으면 거기 뜨는 괄호 안 이름을 알려주세요.

> **아이패드에서도 그대로 됩니다.** USB 허브에 리모컨 수신기를 꽂으면 아이패드가
> 키보드로 인식하기 때문에, 맥에서 쓰던 리모컨을 그대로 쓰면 됩니다. 블루투스 리모컨도 됩니다.
> 아이패드에서도 홈 화면의 **🖱 리모컨 확인**으로 버튼이 잡히는지 미리 볼 수 있습니다.

## 파일 구성

```
기타코드리듬/
  곡 추가하는 법.html   ★ 더블클릭하면 열리는 사용 설명서
  기타게임.command     더블클릭 실행 (맥)
  serve.py             로컬 서버 + 곡 저장 기능
  index.html           화면 구조
  css/style.css        디자인
  js/chords.js         코드 운지 데이터 + 다이어그램
  js/storage.js        곡 목록(songs 폴더) · 설정
  js/audio.js          재생 클럭 · 파형 · 메트로놈 · 효과음
  js/editor.js         채보 에디터
  js/play.js           연주 화면 + 판정
  js/main.js           화면 이동 · 곡 목록 · 설정
  songs/               ★ 곡과 채보가 저장되는 곳
  sw.js                오프라인 저장 기능
  js/gate.js           접속 코드 잠금
  js/access-config.js  ← 접속 코드를 여기서 바꿉니다
  웹에올리기.command    아이패드 + 다른 맥에 반영하기
  최신곡받기.command    다른 맥에서 만든 곡 받아오기
  작업노트.md          ★ 어디까지 했는지 적어두는 곳 (양쪽에서 번갈아 작업할 때)
  CLAUDE.md            Claude가 읽는 프로젝트 안내
```

`연습용 데모 (C-G-Am-F)` 곡이 하나 들어 있습니다. 아이패드에서 잘 열리는지 먼저 확인해 보세요.
필요 없으면 목록에서 삭제하면 됩니다.
