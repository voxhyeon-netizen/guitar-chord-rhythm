곡 추가하는 법

mp3를 넣고 코드를 찍어서 수업용 곡을 만드는 순서입니다.

1

게임 열기

이 폴더의 기타게임.command 를 더블클릭하면 브라우저가 열립니다.

터미널에 ⚠️ 경고가 뜬다면 — 아이클라우드가 음원을 컴퓨터에서 비운 상태입니다. Finder에서 songs 폴더를 열고 구름 아이콘(⬇)을 눌러 받아두세요. 수업 전에 꼭 확인하세요.
2

mp3 넣기

＋ 새 곡 추가 (mp3) 를 누르고 음원 파일을 고릅니다.

고른 파일은 이 폴더의 songs 안으로 복사됩니다. 원본을 지워도 게임은 그대로 돌아갑니다.

3

박자 맞추기 (가장 중요)

마디선이 노래와 맞아야 코드가 제자리에 찍힙니다. 순서대로 하세요.

① BPM 정하기

곡의 BPM을 알면 BPM 칸에 입력합니다. 모르면 노래를 들으면서 탭 템포 버튼을 박자에 맞춰 8번쯤 누르세요. 자동으로 계산됩니다.

② 첫 박 맞추기

Space 로 노래를 재생하다가 첫 박이 나오는 순간 지금을 첫박으로 를 누르세요. 파형의 큰 소리와 마디선이 겹치면 성공입니다.

확인 방법 — 메트로놈 을 켜고 노래를 들어보세요. 딱딱 소리가 노래 박자와 어긋나면 BPM이나 첫박이 아직 안 맞은 겁니다.

③ 스냅 정하기

보통 1마디 또는 1박. 코드가 박자에 딱 붙어서 찍힙니다.

4

코드 찍기

편한 쪽을 쓰세요.

방법 A — 멈춰놓고 찍기 (정확함)

  1. 아래 팔레트에서 코드를 클릭 (예: C)
  2. 타임라인 아래쪽 코드 줄을 클릭하면 그 자리에 놓입니다

방법 B — 들으면서 찍기 (빠름)

  1. Space 로 재생
  2. 코드가 바뀌는 순간 그 코드 버튼을 클릭 하거나 Enter
참고 — 파형의 위쪽을 클릭하면 그 지점으로 이동하고, 아래쪽 코드 줄을 클릭하면 코드가 놓입니다.
5

고치기

하고 싶은 것방법
위치 옮기기노트를 드래그
지우기노트 클릭 후 Delete · 우클릭 · 아래 칩의 ×
코드 바꾸기새 코드를 고른 뒤 같은 자리를 클릭
그 위치 듣기아래 칩(예: C 0:08)을 클릭

단축키

Space재생 / 정지
Enter지금 위치에 선택한 코드 찍기
Delete선택한 노트 삭제
← →한 박씩 이동 (Shift 누르면 0.1초)
⌘+S저장
6

저장하고 확인하기

저장 을 누르면 songs 폴더에 바로 기록됩니다. 따로 내보낼 필요 없습니다.

▶ 연주 테스트 로 바로 연주해 보세요. 코드가 노래보다 이르거나 늦으면 3번(박자 맞추기)으로 돌아가 첫박을 다시 잡으세요.

7

아이패드로 보내기

맥에서 저장→ 웹에올리기.command→ 아이패드 새로고침→ ⬇ 오프라인 저장

맥에서 저장한 것만으로는 아이패드에 넘어가지 않습니다. 웹에올리기를 꼭 한 번 눌러주세요.
주소: https://voxhyeon-netizen.github.io/guitar-chord-rhythm/ · 접속 코드: voxhyeon

다른 맥(맥북)은? 바탕화면이 아이클라우드로 연결돼 있어 자동으로 따라갑니다. 단, 두 맥에서 동시에 채보하지 마세요. 한쪽 작업이 동기화된 뒤 다른 쪽을 여세요.

자주 막히는 것

코드가 노래보다 자꾸 빨라요 / 늦어요

첫박이 안 맞은 겁니다. 3번으로 돌아가 지금을 첫박으로 를 다시 잡으세요. 그래도 점점 어긋나면 BPM이 틀린 것이니 탭 템포를 다시 해보세요.

아이들이 코드를 못 따라와요

⚙ 설정 → 낙하 속도를 3~4초로 올리면 코드가 더 일찍 보입니다. 연주 중 Space → 속도를 0.75x로 낮춰도 좋습니다.

판정이 너무 빡빡해요

⚙ 설정 → 판정 가능 구간(늦게) 를 키우면 넉넉하게 봐줍니다.

아이패드에 새 곡이 안 보여요

맥에서 웹에올리기.command 를 눌렀는지 확인하고, 아이패드에서 새로고침 후 ⬇ 오프라인 저장 을 한 번 더 누르세요.

아이패드에서 소리가 안 나요

측면 무음 스위치와 볼륨을 확인하세요. 화면을 한 번 터치해야 소리가 시작됩니다.

곡을 지우고 싶어요

목록에서 삭제 를 누르면 songs 폴더에서도 지워집니다. 되돌릴 수 없으니 주의하세요.
